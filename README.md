# СколькоСколько — MCP-сервер кабинета клиники

[skolkoskolko.ru](https://skolkoskolko.ru) — сервис сравнения цен частных клиник России. MCP-сервер даёт ИИ-ассистенту владельца клиники доступ к ценам его филиалов: показать прайс, найти строки без кода услуги или с устаревшей ценой, подготовить черновик новых цен. Публикует цены только человек — владелец в личном кабинете после проверки.

Стадия: **пилот** (с ноября 2026). Бесплатно.

> В этом репозитории только описание и примеры подключения. Код сервера закрыт.

## Попробовать без ключа — стенд

Стенд работает без ключа на скрытой тестовой клинике: те же инструменты, цены — пример. Черновик на стенде на сайт не попадает и отменяется через 30 минут.

| | |
|---|---|
| Адрес (Streamable HTTP) | `https://skolkoskolko.ru/api/mcp/demo` |
| Адрес (HTTP + SSE, для Yandex AI Studio) | `https://skolkoskolko.ru/api/mcp/demo/sse` |
| Авторизация | не нужна |
| Лимит | 30 запросов в минуту с одного IP |

GigaCode:
```bash
gigacode mcp add --transport http skolkoskolko-demo https://skolkoskolko.ru/api/mcp/demo
```

Claude Code:
```bash
claude mcp add --transport http skolkoskolko-demo https://skolkoskolko.ru/api/mcp/demo
```

Cursor (`mcp.json`):
```json
{ "mcpServers": { "skolkoskolko-demo": { "url": "https://skolkoskolko.ru/api/mcp/demo" } } }
```

Проверка без клиента:
```bash
curl -s https://skolkoskolko.ru/api/mcp/demo -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

## Рабочий сервер — для клиник

| | |
|---|---|
| Адрес (Streamable HTTP) | `https://skolkoskolko.ru/api/mcp` |
| Адрес (HTTP + SSE) | `https://skolkoskolko.ru/api/mcp/sse` |
| Авторизация | `Authorization: Bearer skm_…` — ключ владельца клиники |
| Где взять ключ | личный кабинет клиники → «ИИ-ассистент» (https://skolkoskolko.ru/lk/ai/) |
| Срок ключа | 30 дней, отзыв в кабинете в один клик |

Ключ открывает только филиалы своей клиники. Вид ключа: «чтение» или «черновики цен».

## Инструменты

| Инструмент | Что делает |
|---|---|
| `list_my_branches` | Филиалы, к которым у владельца ключа есть доступ |
| `get_branch_summary` | Обзор филиала: адрес, лицензия, сколько цен, сколько без кода услуги, свежесть цен, открытый черновик |
| `get_prices` | Строки прайса: поиск по названию, фильтры «без кода», «устаревшие», «вне прайса», «введённые вручную» |
| `propose_price_changes` | Черновик изменения цен. Ничего не публикует: черновик проверяет и публикует владелец в кабинете |
| `import_prices_from_url` | Загрузить прайс по ссылке в черновик (только рабочий сервер, на стенде выключен) |
| `get_draft_status` | Состояние черновика: ждёт проверки, опубликован, отменён |

Код услуги — код по номенклатуре медицинских услуг Минздрава (приказ № 804н).

## Данные и безопасность

- Через сервер передаются только цены и карточка филиала. Заявок, данных пациентов, имён, телефонов и e-mail сотрудников нет.
- Изменить цены на сайте сервер не может: только черновик, публикует человек.
- Запросы ассистенту обрабатывает выбранный клиникой ИИ-сервис по своим правилам.

## Клиенты

Проверено: GigaCode (CLI и Desktop), Yandex AI Studio (агенты — через HTTP + SSE). Подойдут Cursor, Claude Code и любой MCP-клиент с Streamable HTTP или HTTP + SSE.
